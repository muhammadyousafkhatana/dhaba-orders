# Dhaba Orders

A microservices-based restaurant ordering application.

## Architecture

- web: React, Vite and Nginx
- menu-api: Python and FastAPI
- orders-api: Go
- kitchen-worker: Java and Spring Boot
- stats-api: PHP and Laravel
- postgres: PostgreSQL
- redis: Redis
- ops-monitor: Shell-based monitoring

## Infrastructure

- AWS EC2
- K3s Kubernetes
- AWS ECR
- GitHub Actions
- Kustomize

## Environments

- Staging
- Production
- Operations
